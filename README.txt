STOCKAI — SIMPLE INSTALL

For Windows:
1. Double-click Install_StockAI.bat
2. Wait for the first-time setup (usually a few minutes).
3. StockAI opens automatically and a desktop shortcut is created.
4. After that, double-click the StockAI desktop shortcut whenever you want to use it.

NO DATA UPDATES ARE NEEDED:
StockAI downloads current market data when it runs. The app does not contain a fixed stock-price database that needs manual replacement.

The first launch needs an internet connection to install the components and download market data.

This is an educational research tool, not a guarantee of profit or personalized financial advice.
